Apple’s Foundation Models framework has brought the power of large language models to the one device that people keep close for the majority of their day — the iPhone. And it’s enabled developers to build intelligent features using a privacy focussed framework — at zero cost for developers. But it does so much more — from type-safe guided generation using the `@Generable` macro to native tool calling. And now, with the ability to tap into the power of cloud-hosted models like Apple’s own Private Cloud Compute and third party models like Claude and Gemini, developers can architect applications that make the best use of the capabilities of the most suitable model.

This talk provides a comprehensive blueprint for building intelligent features using the LanguageModelSession API. You will learn:

- How to generate type-safe output using the `@Generable` macro
- Using native tool calling to connect models to the capabilities of your app
- Tapping into the power of cloud-hosted models like PCC, Claude, and Gemini
- Implementing agentic features using Dynamic Profiles

All using the language you know and love — Swift!

We’re going to focus on the agentic features of Apple’s Foundation Models framework.
